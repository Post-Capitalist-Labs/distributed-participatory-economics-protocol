## Decisions for the author (recommendations in the book, labelled "proposed, for author ratification")

1. **Signature policy:** tiered (recommended): per-round objects classical with per-round k-of-n post-quantum anchoring (BFT: 3-of-5 federation SLH-DSA; log: 11-of-16 ML-DSA-44 cosignatures plus an annual 3-of-5 SLH-DSA backstop); long-lived objects hybrid; confidentiality hybrid ML-KEM.
2. **Layer 1 at Kill Gate 2:** test both BFT checkpoints and a witnessed log (recommended); CometBFT stays the reference BFT engine.
3. **S7 for pilots:** council-level allocation for staples plus attributed receipts held by the home council for rationed goods, with an online check where possible and offline collection only at the home depot (at most one credit cap per person per day); the household privacy claim is narrowed to annual requests until a point-of-use design is specified and tested (recommended).
4. **Aggregator count for Phase 3:** K = 2 on DAP with an existing server for pilots; K = 3 only if a pilot shows a governance case (recommended).
5. **Primary client:** native Android/iOS apps over the Rust core via UniFFI; web client for exploration, accessibility and Phase 1H (recommended).
